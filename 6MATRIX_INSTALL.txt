METHOD 1: Extract to Repository (Recommended)
──────────────────────────────────────────────

1. Navigate to your 4liod/4liod repository:
   cd /path/to/4liod/4liod

2. Create the 3SRC directory if it doesn't exist:
   mkdir -p 3SRC

3. Extract the archive into 3SRC:
   tar -xzf /path/to/6MATRIX.tar.gz -C 3SRC/

4. Rename the extracted directory:
   mv 3SRC/matrix6 3SRC/6MATRIX

5. Add to git:
   git add 3SRC/6MATRIX
   git commit -m "Add 6MATRIX modular terminal system"
   git push

METHOD 2: Manual Upload to GitHub
──────────────────────────────────

1. Extract the archive locally:
   tar -xzf 6MATRIX.tar.gz

2. Navigate to: https://github.com/4liod/4liod/tree/main/3SRC

3. Click "Add file" → "Upload files"

4. Upload the entire matrix6 folder contents

5. Rename to 6MATRIX via GitHub interface

╔══════════════════════════════════════════════════════════════════╗
║                   FEATURES & HIGHLIGHTS                           ║
╚══════════════════════════════════════════════════════════════════╝

✨ MODULAR ARCHITECTURE:
   - Command Pattern for easy extensibility
   - Auto-discovery of new commands
   - Separated concerns (MVC-like)
   - RESTful API endpoint

✨ REAL SYSTEM SPECS:
   - Fetches actual CPU, RAM, disk info
   - Reads from /proc/cpuinfo and /proc/meminfo
   - Detects HyperThreading, Virtualization, NX Bit
   - Shows real Linux distribution and kernel version

✨ TERMINAL INTERFACE:
   - Matrix rain animation
   - BIOS boot sequence with real hardware
   - Glitch effects
   - Portal interface for SHA-1 decryption
   - Command history navigation (up/down arrows)

✨ SECURITY:
   - Read-only system info queries
   - Optional shell execution (disabled by default)
   - Input sanitization
   - Configurable security settings
